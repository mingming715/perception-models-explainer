항목 StreamPETR Sparse4D v1 Sparse4D v2 Sparse4D v3

현재 외에 보는 것 메모리 쿼리 (+ 현재 이미지만) 과거 T프레임 이미지 feature 이전 instance 상태 (+ 현재 이미지만) v2와 동일

한 줄로

v1은 과거 이미지를 다시 샘플링하고, StreamPETR / v2 / v3는 sparse instance·query 상태를 재귀적으로 넘깁니다. v3는 그 추론 경로를 유지한 채 학습·attention 구조를 다듬은 버전입니다.

Foundation4D(Scene Token)는 시간 상태를 쿼리로 넘기는 대신, 카메라·시간 방향으로 나눈 attention으로 윈도우 전체를 조밀한 공유 토큰으로 만들고, 그 위에서 깊이·검출·occupancy·Gaussian을 함께 추정하는 다른 축입니다. 해설로 이동

논문 원문(arXiv) method·표를 옮긴 학습용 해설입니다. 실험 수치는 각 논문 Table을 인용했으며 창작하지 않았습니다. 원 논문은 동기화된 멀티 카메라 프레임을 가정합니다.
